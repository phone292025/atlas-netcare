## What is actually left

The code is finished. All seven modules are built, every functional requirement has code and a test, and the verification commands are clean.

What remains needs people, not programming.

**Twenty-one per-member artefacts.** A Data Flow Diagram Level 1, a data dictionary and a flowchart, for each of the seven modules. They are individually assessed, so each owner has to be able to explain theirs. The skeleton exists: the numbered processes in [12-system-diagrams.md](../docs/12-system-diagrams.md) Figure 2 are the module numbers, so a DFD 1 is one process expanded.

**Nobody owns a module.** Every spec still says unassigned. Nothing per-member can start until that changes, which makes it the most valuable ten minutes the next team meeting can spend.

**Four UAT sessions** with real participants, real feedback, and what changed as a result.

**The non-functional timings** need measuring rather than estimating.

**The cover sheet**, with group number, the name and signature table, and the plagiarism declaration.

**Written confirmation from Mr Dhason** that Category 4, predictive maintenance, is the agreed case study.

**The reference list and the Gantt chart**, both of which live in the Word document.

The four whole-system diagrams are done and are in [12-system-diagrams.md](../docs/12-system-diagrams.md). The Installation Guide is done and is in [11-installation-guide.md](../docs/11-installation-guide.md).
