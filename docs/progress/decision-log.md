**Write an [ADR](../decisions/) instead when:** the decision shapes the architecture, adds a dependency, or someone will later ask "why is it like this?"

| 2026-09-09 | **A driver declares what it polls, and the stale sweep only judges those.** `markStaleOffline()` marks a device offline when it has gone quiet, and it asked `AccessPoint::collectable()` — every access point the system watches. **Silence is only evidence of failure if somebody was listening.** An access point no driver pings is not quiet, it is unasked, and marking it offline raises a ticket about hardware nothing tried to reach. `TelemetrySource` now has `pollable(): Builder` and the sweep uses it. **Both shipped drivers poll everything, so this changes no behaviour today** — it is a seam, not a live fix, and it is worth being clear about that rather than overselling it.
