# Decision Log

> **Last updated:** 2026-08-28

Small calls that affect other people but do not warrant a full ADR. One line each. Newest at the top.

**Write an entry when:** you rename something shared, change a shared file, choose between two equally reasonable implementations, or discover something that changes how someone else should work.

**Write an [ADR](../decisions/) instead when:** the decision shapes the architecture, adds a dependency, or someone will later ask "why is it like this?"

| Date | Decision | Made by | Affects |
|---|---|---|---|
| 2026-08-28 | **Never nest a Blade comment inside a Blade comment.** The inner closing token ends the outer one, and everything after it becomes live template code. A usage example inside a component docblock then gets compiled and evaluated — `<x-risk-gauge :score="$assessment->score" />` in a comment threw "Attempt to read property on null" from a file that looked inert. Keep examples in plain indented text. | Stage 3c | Everyone |
| 2026-08-28 | `Tone` gained three surfaces in 3c: `solid()` for gauge fills, `choice()` for `peer-checked:` states, and `chart()` for hex, since a canvas cannot use a Tailwind class. `choice()` is written out in full rather than derived from `badge()` with a prefix — a prefixed class is assembled at runtime, never seen by Tailwind's scanner, and every selected choice on the inspection form would render colourless. | Stage 3c | Everyone |
| 2026-08-28 | `App\Support\FormField` holds the id and error-key derivations shared by `<x-form.field>` and the three controls. Four files must agree, or a label silently stops focusing its input and an error stops being announced with it. An input named `results[12][remark]` gets id `results-12-remark` and validates under `results.12.remark`. | Stage 3c | Everyone |
| 2026-08-28 | The tone to class mapping moved out of `badge.blade.php` into **`app/Support/Tone.php`**, with one method per surface: `badge()`, `banner()`, `accent()`. Stage 3b added `<x-alert>`, which needs the same four tones in different classes, and 3c adds a third surface in `<x-risk-gauge>`. Adding a surface means adding a method there. Never write a `match` on a tone anywhere else. | Stage 3b | Everyone |
| 2026-08-28 | `./app/**/*.php` added to `content` in `tailwind.config.js`, because `Tone.php` now holds literal class names and Tailwind only generates classes it can see in a scanned file. Removing that line silently strips the colour from every badge and alert in the system. | Stage 3b | Everyone |
| 2026-08-28 | Flash messages are rendered by `layouts/app.blade.php` through `<x-alert>`, for four session keys: `status` (Breeze), `success`, `warning`, `error`. Redirect with `->with('success', '...')`. Do not hand-roll a banner on a page. | Stage 3b | Everyone |
| 2026-08-28 | **Always run `php artisan view:clear` before `npm run build`.** `./storage/framework/views/*.php` is in the Tailwind `content` array (a Laravel default), so **compiled Blade views count as source**. CSS size therefore depends on whether `view:cache` has been run, and a deleted view keeps contributing classes until its compiled artifact is cleared. Measured on identical source: **42,191 bytes with views cleared, 54,035 with views cached** — an 11.8 KB swing. Quote the cleared figure. | Stage 3b review | Everyone |

Clearing Vite's cache does not change the outcome; clearing the *view* cache does. | Stage 3b review | Everyone |
| 2026-08-27 | `EnsureUserHasRole` uses `! ($user->is_active ?? true)`, not `=== false`. An uncast boolean column returns `int(0)` from Eloquent, so a strict comparison never matches and the guard fails **open**. A missing attribute counts as active. Still add the `boolean` cast to `User` in Stage 4. | Stage 2 review | M1 |
